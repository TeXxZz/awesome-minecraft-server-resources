# Awesome Minecraft Server Resources

A curated list of tools, directories, and resources for Minecraft server owners and players. Contributions welcome — open a pull request.

---

## 📋 Server Lists & Directories

Find and list Minecraft servers ranked by votes, players, and activity.

- [MinecraftServers-List](https://minecraftservers-list.com) — Server list ranked by real player votes with uptime monitoring, reviews, and gamemode filtering. Java & Bedrock.
- [Planet Minecraft](https://www.planetminecraft.com/servers/) — Large community server directory with screenshots and community ratings.
- [Minecraft Server List](https://minecraft-server-list.com) — Long-running directory with vote-based rankings.
- [Minecraft-MP](https://minecraft-mp.com) — Server list with status monitoring and player counts.
- [TopG](https://topg.org/minecraft-servers) — Multi-game directory with Minecraft server listings.
- [Minecraft Servers](https://minecraftservers.org) — Vote-based server rankings with tag filtering.

## 🛠️ Server Management Tools

Tools for running, configuring, and managing a Minecraft server.

- [MCToolsHub](https://mctoolshub.com) — Server tools, guides, and resources for server owners including MOTD builders and color code generators.
- [MCPlayerTools](https://mcplayertools.com) — Free tools for players and server owners: gradient text, give command builder, player head generator, HUD customizer and more.
- [MCSrvStat](https://mcsrvstat.us) — Free server status checker and API. Check if a server is online and get player counts.
- [Votifier Tester](https://minecraftservers-list.com/votifier-tester) — Test your Votifier/NuVotifier setup without needing to cast a real vote.
- [MOTD.gg](https://motd.gg) — Online Minecraft MOTD creator with color and formatting preview.

## 🎨 Player Tools & Generators

Tools for creating in-game content.

- [MCPlayerTools — Give Command Builder](https://mcplayertools.com/tools/give-command) — Build complex /give commands with enchantments, custom names, and lore for all Java versions.
- [MCPlayerTools — Gradient Text](https://mcplayertools.com/create/gradient-text) — Generate gradient colored text for signs, books, and chat.
- [MCPlayerTools — Player Head Generator](https://mcplayertools.com/create/player-heads) — Get the /give command for any player's head by username.
- [Minecraft Color Codes](https://mcplayertools.com/tools/color-codes) — Full reference for Minecraft formatting and color codes.
- [NameMC](https://namemc.com) — Look up Minecraft player profiles, skin history, and UUID.
